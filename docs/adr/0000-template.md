# ADR-0000: Title in the imperative

- **Status:** Proposed | Accepted | Superseded by ADR-XXXX
- **Date:** YYYY-MM-DD
- **Deciders:** Project team

## Context

What forces the decision? State the requirement, the constraint, and any
numbers that matter. If a number is an estimate, say so.

## Decision

One sentence. Then the reasoning.

## Alternatives considered

For each one: what it is, what it would have given us, and the specific
reason it was rejected. Reject alternatives on the requirement, never on
taste or popularity. If an alternative is genuinely close, say that.

## Consequences

**Positive** — what this buys.

**Negative** — what it costs. Be honest; every decision costs something.

**Mitigations** — what we do about the negatives.

## Revisit if

The conditions under which this decision stops being correct. A decision
with no such conditions has not been thought through.
